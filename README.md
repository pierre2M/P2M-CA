## Description
P2M-CA est un modèle relationnel fondé sur des registres sémantiques permettant l'enregistrement d'interactions multi-acteurs, conforme à la théorie de l'acteur-réseau. Il permet d'appréhender les communs ostromiens, l'approche par les communs ou encore la méthologie C.A.R.E. Il vise en particulier à faciliter traduction comptable de la notion juridique de communalité. Il pourra aussi être mobilisé pour des approches méso-économiques à l'échelle de filières, par exemple dans le cadre de l'exercice du devoir de vigilance, ou encore pour la production de rapport de durabilité ou encore dans l'engagement pour une responsabilité territoriale de l'entreprise.
